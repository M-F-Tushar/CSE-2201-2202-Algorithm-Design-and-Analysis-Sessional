## 1. Primary Textbook

### Introduction to Algorithms (CLRS)
- **Authors:** Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, Clifford Stein
- **Edition:** 4th Edition (MIT Press / McGraw-Hill)
- **Significance:** The definitive reference and syllabus benchmark for CSE 2201. Chapters across this repository follow its asymptotic notation, recurrence formulation, pseudocode style, and terminology.
- **Coverage in Course:**
  - Foundations & Asymptotics (CLRS Chapters 1–3)
  - Sorting & Order Statistics (CLRS Chapters 6–9)
  - Advanced Design & Analysis: Greedy, Dynamic Programming (CLRS Chapters 14–15)
  - Graph Algorithms: BFS, DFS, MST, Shortest Paths, Maximum Flow (CLRS Chapters 20–24)
  - Selected Topics: NP-Completeness, Approximation Algorithms (CLRS Chapters 34–35)

## 2. Supplementary Textbooks

### Algorithm Design
- **Authors:** Jon Kleinberg and Éva Tardos
- **Publisher:** Pearson / Addison-Wesley
- **Focus:** Outstanding for developing algorithmic intuition, proof techniques, greedy-choice arguments, and network flow applications. Highly recommended for understanding why algorithms are correct.

### Algorithms
- **Authors:** Sanjoy Dasgupta, Christos Papadimitriou, Umesh Vazirani
- **Publisher:** McGraw-Hill
- **Focus:** Crisp, concise, and conceptually luminous explanations of divide-and-conquer, dynamic programming, and NP-completeness.

### Computer Algorithms / C++
- **Authors:** Ellis Horowitz, Sartaj Sahni, Sanguthevar Rajasekaran
- **Publisher:** Silicon Press / Computer Science Press
- **Focus:** Traditional academic syllabus benchmark for state-space search, backtracking (N-Queens, Graph Coloring), branch-and-bound (LC-search, Knapsack, TSP), and lower bound theory.

## 4. Interactive Visualizers and Online Tools

- **[VisuAlgo](https://visualgo.net/)** — Interactive visualizations and step-by-step animations for sorting, BSTs, heaps, graph traversals, Dijkstra, Bellman-Ford, Kruskal, Prim, and Max Flow.
- **[Algorithm Visualizer](https://algorithm-visualizer.org/)** — Interactive online platform that visualizes code execution side-by-side with data structures.
- **[Excalidraw](https://excalidraw.com/)** — Open-source whiteboard tool used to author all 180+ editable architectural and algorithmic diagrams in this repository.

---

## 5. Practice and Problem Archives

- **[LeetCode](https://leetcode.com/)** — Standard platform for technical problem solving, particularly dynamic programming, backtracking, graphs, and two-pointer techniques.
- **[Codeforces](https://codeforces.com/)** — Competitive programming contest platform with extensive tag-based archives for trees, segment trees, and flows.
- **[CSES Problem Set](https://cses.fi/problemset/)** — Clean, concise collection of fundamental algorithmic problems (Sorting & Searching, Dynamic Programming, Graph Algorithms, Tree Algorithms, Range Queries).
